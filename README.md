#  Hospital Management System
 
A console-based Hospital Management System developed using **Core Java, JDBC, and MySQL** following the **MVC Architecture**.  

This project helps manage hospital operations such as patient records, doctor management, appointments, and billing efficiently.
 
 
#Features
 
✅ Patient Management  

✅ Doctor Management  

✅ Department Management  

✅ Appointment Booking  

✅ Billing System  

✅ CRUD Operations  

✅ Database Connectivity using JDBC  

✅ MVC Architecture Implementation  
 
 
# Technologies Used
 
- Core Java

- JDBC

- MySQL

- Eclipse IDE

#  Database
 
This project uses **MySQL Database** for storing and managing hospital records.
 
### Main Tables

- Patients
- Doctors
- Departments
- Appointments
- Billing

 
#  How to Run the Project
 
1. Clone the repository
2. Open the project in Eclipse IDE
3. Configure MySQL database
4. Update database credentials in DBUtil.java
5. Run the Main Class
